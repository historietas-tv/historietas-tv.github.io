Política de privacidad

InicioTérminos del servicioPolítica de privacidad

Última actualización: 8 de noviembre de 2026

Resumen

Historietas es una herramienta personal que solo usa su autor, con sus propias cuentas. No recoge datos de otras personas, no tiene servidores propios y no comparte ni vende información.

Qué datos se usan

  • Tokens de acceso OAuth que emite cada plataforma (YouTube, TikTok o Instagram) cuando el autor autoriza la herramienta.
  • Información básica del perfil del autor: el nombre del canal o del perfil, para confirmar que la cuenta es la correcta.
  • Los vídeos y sus textos (título, descripción y hashtags), que crea el propio autor.

Para qué se usan

Solo para subir los vídeos del autor a sus propias cuentas. No se analizan, no se usan para publicidad y no se combinan con otros datos.

Dónde se guardan

Los tokens y los datos del perfil se guardan solo en el ordenador del autor, en ficheros locales con acceso restringido. Nunca se envían a servidores distintos de las API oficiales de cada plataforma.

Con quién se comparten

Con nadie. Los vídeos solo se envían a la plataforma de destino elegida por el autor.

Conservación y borrado

Los tokens se conservan mientras la herramienta esté en uso y se pueden borrar en cualquier momento eliminando los ficheros locales. El acceso también se puede revocar desde los ajustes de cada plataforma:

  • Google/YouTube: myaccount.google.com/permissions
  • TikTok: Ajustes y privacidad → Seguridad → Apps y servicios
  • Instagram: Configuración → Apps y sitios web

El uso de los datos de las API de Google por parte de Historietas cumple la política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Privacy Policy (English)

Last updated: November 8, 2026

Summary

Historietas is a personal tool used only by its author, with the author's own accounts. It collects no data from other people, runs no servers of its own, and never shares or sells information.

Data used

  • OAuth access tokens issued by each platform (YouTube, TikTok or Instagram) when the author authorizes the tool.
  • Basic profile information of the author, such as the channel or profile name, to confirm that the right account is connected.
  • The videos and their text (title, description and hashtags), created by the author.

Purpose

Only to upload the author's videos to the author's own accounts. Data is not analyzed, not used for advertising and not combined with other data.

Storage

Tokens and profile data are stored only on the author's computer, in local files with restricted access. They are never sent anywhere except the official APIs of each platform.

Sharing

None. Videos are sent only to the destination platform chosen by the author.

Retention and deletion

Tokens are kept while the tool is in use and can be deleted at any time by removing the local files. Access can also be revoked from each platform's settings (links above).

Historietas' use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
